# SkinAI Vue

Vue 3 + Vite 기반 AI 피부 시술 추천 데모 앱입니다. 사용자가 얼굴 또는 상담받고 싶은 피부 부위를 촬영하거나 업로드하면, 데모 분석 진행 화면을 거쳐 추천 시술, 피부 지표, AI 시술 상담, 근처 병원 결과지 제출, 분석 기록을 확인할 수 있도록 구성되어 있습니다.

## 실행 방법

```bash
corepack pnpm install
corepack pnpm dev
```

개발 서버 실행 후 터미널에 표시되는 로컬 주소로 접속합니다.

## 스크립트

```bash
corepack pnpm dev      # 개발 서버 실행
corepack pnpm build    # 타입 체크 후 프로덕션 빌드
corepack pnpm preview  # 빌드 결과 미리보기
corepack pnpm lint     # vue-tsc 기반 타입 검사
```

## 주요 기술

- Vue 3
- Vite
- TypeScript
- Vue Router
- Tailwind CSS v4

## 실제 화면 미리보기

### 홈

<img src="readme-screens/home-delay.png" alt="홈 화면" width="320" />

홈 화면은 앱 진입점입니다. 사용자는 첫 화면에서 시술 추천을 시작하거나 최근 추천 리포트, AI 상담, 병원 찾기, 분석 기록으로 이동할 수 있습니다. 병원 결과지를 제출한 이력이 있으면 최근 신청 현황도 함께 표시됩니다.

### 시술 추천 촬영

<img src="readme-screens/capture.png" alt="시술 추천 촬영 화면" width="320" />

촬영 화면은 카메라 사용 흐름에 맞춘 전체 화면 UI입니다. 사용자는 상담받고 싶은 부위가 잘 보이도록 맞춘 뒤 촬영하거나, 갤러리에서 이미지를 선택할 수 있습니다.

### 추천 분석 진행

<img src="readme-screens/loading.png" alt="추천 분석 진행 화면" width="320" />

분석 진행 화면은 사용자가 기다리는 동안 현재 처리 단계를 확인할 수 있게 합니다. 피부 영역 감지, 피부 톤 분석, 모공 및 결 분석, 시술 상담 포인트 정리, 맞춤 시술 추천 생성 순서로 진행됩니다.

### 시술 추천 결과

<img src="readme-screens/result-delay.png" alt="시술 추천 결과 화면" width="320" />

결과 화면은 추천 리포트의 중심 화면입니다. 추천 적합도와 피부 타입을 먼저 보여주고, 추천 시술별 목적과 상담 시 확인할 점, 수분/유분/모공/색소침착 지표, 상담 전 체크리스트를 제공합니다.

### AI 시술 상담

<img src="readme-screens/chat.png" alt="AI 시술 상담 화면" width="320" />

AI 시술 상담 화면은 추천 결과를 바탕으로 추가 질문을 하는 공간입니다. 추천 질문을 선택하거나 직접 입력하면 시술 목적, 우선순위, 주의사항 등을 데모 응답으로 확인할 수 있습니다.

### 분석 기록

<img src="readme-screens/history.png" alt="분석 기록 화면" width="320" />

분석 기록 화면은 시간에 따른 점수 변화를 보여줍니다. 최근 점수, 지난 분석 대비 변화량, 최근 5회 그래프, 날짜별 상세 기록을 한 화면에서 확인할 수 있습니다.

## 사용자 흐름

1. 홈 화면에서 `시술 추천 시작하기`를 선택합니다.
2. 촬영 화면에서 이미지를 촬영하거나 갤러리에서 업로드합니다.
3. `시술 추천 받기`를 누르면 분석 진행 화면에서 처리 단계와 진행률을 확인합니다.
4. 분석이 완료되면 결과 화면에서 추천 적합도, 피부 지표, 추천 시술, 상담 전 체크리스트를 확인합니다.
5. 추가 질문이 있으면 AI 시술 상담으로 이동해 추천 시술의 우선순위와 주의사항을 확인합니다.
6. 근처 병원 찾기 화면에서 추천 시술과 매칭되는 병원을 선택하고, 결과지 제출 항목을 선택해 제출합니다.
7. 분석 기록 페이지에서 이전 결과와 점수 변화를 확인합니다.

## 데모 데이터 기준

### 추천 결과 예시

- 추천 적합도: 78점
- 피부 타입: 복합성
- 주요 고민: T존 유분 과다, 볼 색소침착, 수분 부족
- 추천 시술:
  - 리쥬란 힐러: 볼 건조와 피부결 개선 상담에 적합
  - 피코토닝: 볼 부근 색소침착 완화 목적에 적합
  - 아쿠아필: T존 유분과 모공 관리 보조 추천
- 피부 지표:
  - 수분: 72점, 보통
  - 유분: 65점, 주의
  - 모공: 85점, 좋음
  - 색소침착: 68점, 보통
- 상담 전 체크리스트:
  - 시술 전 1주일은 강한 각질 케어 피하기
  - 상담 시 색소침착 부위와 민감도 공유하기
  - 시술 후 자외선 차단과 보습 계획 세우기

### 병원 추천 예시

| 병원 | 거리 | 평점 | 매칭 시술 | 상담 가능 시간 |
| --- | ---: | ---: | --- | --- |
| 서울스킨 피부과의원 | 0.8km | 4.8 | 리쥬란 힐러, 피코토닝 | 오늘 상담 가능 |
| 메디톤 클리닉 | 1.4km | 4.6 | 피코토닝, 아쿠아필 | 내일 오전 가능 |
| 더맑은 피부의원 | 2.1km | 4.7 | 리쥬란 힐러 | 이번 주 상담 가능 |

병원 결과지 제출 정보는 브라우저 `localStorage`의 `skinai:hospital-applications` 키에 저장됩니다. 제출 후 홈 화면의 병원 신청 현황에서 최근 제출 내역을 확인할 수 있습니다.

## 폴더 구조

```text
src/
  components/   공통 UI 컴포넌트
  lib/          데모 데이터, 타입, 병원 신청 localStorage 유틸
  views/        라우트별 페이지 컴포넌트
  App.vue       앱 루트 컴포넌트
  main.ts       Vue 앱 진입점
  router.ts     페이지 라우팅 설정
  styles.css    Tailwind CSS v4 테마와 전역 스타일

public/         정적 이미지와 아이콘
readme-screens/ README 화면 미리보기 이미지
```

## 참고 사항

- 현재 앱은 백엔드 API 없이 동작하는 프론트엔드 데모입니다.
- 촬영 버튼은 실제 카메라 스트림을 연결하지 않고 `/placeholder.jpg`를 결과 이미지로 사용하는 데모 동작입니다.
- AI 상담 응답과 추천 결과는 `src/views` 내부에 정의된 정적 데모 데이터와 조건 분기 응답을 사용합니다.
- 병원 결과지 제출 내역은 브라우저 로컬 저장소에만 저장됩니다.
